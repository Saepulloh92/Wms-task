Lupa PIN admin? (darurat)

Minta admin lain mengatur ulang PIN Anda lewat menu User & Area. Hanya jika tidak ada admin lain, tombol di bawah menghapus SEMUA PIN di perangkat ini (data pemeriksaan tetap). Anda harus mengetik RESET dan menunggu 3 detik. Setelah itu atur PIN admin lagi di menu User & Area.

Lupa password admin? (darurat)

Minta admin lain mengatur ulang password Anda lewat menu User & Area. Hanya jika tidak ada admin lain, tombol di bawah menghapus SEMUA password di perangkat ini (data pemeriksaan tetap). Anda harus mengetik RESET dan menunggu 3 detik. Setelah itu atur password admin lagi di menu User & Area.

Telegram

Kirim informasi pemeriksaan ke grup atau chat Telegram lewat bot Anda.

Cara membuat bot

Buat bot lewat @BotFather, lalu masukkan bot ke grup (atau kirim satu pesan ke bot). Tombol "Ambil Chat ID" membaca pesan terakhir yang diterima bot.

Kirim otomatis

Laporan lain

Laporan lain (rekap DC, KPI, laporan muat, file Adjust) dikirim lewat tombol "Kirim ke Telegram" di halamannya masing-masing.

Pesan yang gagal karena tidak ada sinyal ditahan di perangkat dan dikirim otomatis saat koneksi kembali. Token hanya disimpan di perangkat ini dan tidak ikut file cadangan. Siapa pun yang memegang perangkat ini bisa membacanya, jadi pakai bot khusus gudang.

Tentang area

Area dipakai untuk pemeriksaan per bin dan cek kesesuaian. Bin-nya datang dari kolom Area di Informasi Rak WMS, jadi nama area harus sama persis.

Status area

Keamanan & mode periksa

Password dan peran adalah pencegah salah pakai di perangkat bersama, bukan keamanan tingkat tinggi: data tetap ada di browser perangkat ini.

Atur ulang password

Untuk satu user, pilih Ubah di daftar user lalu isi password baru. Tombol di bawah menghapus password SEMUA user, termasuk password Anda, dan akses jadi terbuka sampai admin membuat password lagi.

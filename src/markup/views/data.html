Data acuan WMS

Impor Informasi Rak dari WMS (Excel atau CSV). Hasil pemeriksaan lama dikosongkan.

Format file

Kolom wajib: Area, Rak (atau Bin), Kode Item, Nama Item, Onhand. Baris judul di atas header diabaikan.

Sinkron Google Sheets

Hasil periksa, DC, tugas, dan petugas disinkronkan antar perangkat dan tersalin ke Google Sheets Anda. Tanpa PIN.

Cadangan data

Isi cadangan

Cadangan memuat data WMS, hasil periksa, DC, petugas, dan status area. Simpan filenya di tempat aman (misalnya kirim ke WhatsApp sendiri).
